# Federico Battistella

Lavoro in [A.R. AUTO](https://arautoricambi.com), magazzino di ricambi auto in Lombardia.
Costruisco le webapp e le automazioni interne dell'azienda: gestione del magazzino,
portale clienti, ricerca ricambi e integrazioni con il gestionale.

**Progetti pubblici**
- [quote-import-ext](https://github.com/federico-cyber/quote-import-ext): estensione Chrome che importa i preventivi Qricambi nel gestionale
- [sirj-fkey-shortcuts](https://github.com/federico-cyber/sirj-fkey-shortcuts): ripristina i tasti F1-F12 del gestionale SIRJ in Chrome, anche su macOS e Linux
- [synapse-lab](https://github.com/federico-cyber/synapse-lab): siti web per clienti
